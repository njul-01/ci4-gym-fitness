# Gym & Fitness Management System

Web-based management system for gym and fitness center administration.

## Description

This project is a web-based application developed to support the administration and management of a gym and fitness center. The system provides features for managing members, memberships, trainers, classes, schedules, class bookings, and reports.

This project was developed as an academic and learning project to implement web development concepts using the CodeIgniter 4 framework and MySQL database.

## Technologies

* PHP
* CodeIgniter 4
* MySQL
* Bootstrap 5
* HTML
* CSS
* JavaScript

## Main Features

* Member Management
* Membership Management
* Trainer Management
* Class Management
* Schedule Management
* Class Booking
* Dashboard
* Reports
* CRUD Operations
* Form Validation

## System Architecture

This application uses the **Model-View-Controller (MVC)** architecture provided by CodeIgniter 4.

* **Model** — Handles database operations and application data.
* **View** — Handles the user interface and presentation.
* **Controller** — Handles application logic and connects Models with Views.

## Database

The application uses **MySQL** as its database management system.

Main data managed by the system includes:

* Members
* Memberships
* Trainers
* Classes
* Class Schedules
* Class Bookings

## Project Status

**Academic / Learning Project**

The project was developed to practice web application development, database management, CRUD operations, MVC architecture, form validation, and backend development using CodeIgniter 4.

## Notes

This repository does not include environment configuration files or sensitive database credentials.

Before running the application, configure the local `.env` file according to your environment.
